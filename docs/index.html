Before you blame the server

One glance tells you whose problem it is

When something online stops working, every app reports it its own way. A browser says the site can't be reached. A game says it lost the server. A call says the other person's connection is unstable. None of them tells you if the fault is on your side.

  • A page won't load

    Before you refresh it ten times or decide the site is down, look at the tray.

  • A game lags or kicks you out

    Before you switch servers or blame the game, check whether your internet dropped. Set the interval to 1 second and even a short drop shows up mid-match.

  • A call freezes

    Before you ask the other person to reconnect, find out whose connection actually went.

Screen glows, icon is red

It's your connection

Neither Google nor Cloudflare answers, so the problem is on your side. Check the Wi-Fi or cable, restart the router or wait it out. Refreshing the page or picking another game server won't help.

No glow, icon is green

Your internet is fine

Your computer reaches the internet, so the site or game server you're using is the likely culprit. Check its status page or try again later.

ICMP echo · 1500 ms timeout

Two big providers, not one server

To tell your connection apart from one bad server, IsConnected asks two independent ones. Each check starts with Google's public DNS. If it stays silent, Cloudflare gets one try before the app decides you're offline. Both going down at once is far less likely than your own line dropping.

  1. 8.8.8.8

    Ping the primary

    One echo request to Google Public DNS. A reply inside 1.5 seconds means you're online and the cycle ends here.

  2. 1.1.1.1

    Fall back once

    No reply? One more request goes to Cloudflare DNS in the same cycle. Either answer counts as connected.

  3. Online Offline

    Show the result

    The tray icon turns green or gets a red slash. With Highlight issue on, the glow starts and keeps pulsing until a ping comes back.

30 seconds by default. Each wait shifts by up to ±10 % (never more than 5 s), so many installs on one network don't all ping at the same instant.

Left- or right-click the tray icon

The whole app is one menu

There is no main window and no dashboard. Everything IsConnected does is a line in its tray menu, shown here as it appears on your taskbar.

  • Online, 14 ms via 8.8.8.8 (last check 14:02:11)
    Status line. Round-trip time, which host answered and when the last check ran.
  • ✓Autostart
    Start with Windows. Writes to your own HKCU\…\Run key, so no administrator rights are needed.
  • ✓Highlight issue
    Glow on outage. A pulsing colored glow around your screens while you're offline, on top of the page or game in front of you. It ignores clicks, so nothing gets in your way.
  • Show current speed
    Live throughput. A small always-on-top readout of download and upload in MB/s. It reads Windows interface counters and sends no traffic of its own.
  • Speed overlay corner ▸
    Top left, top right, bottom left or bottom right of the primary screen.
  • Highlight area ▸
    Every connected screen, a single edge, or one corner: nine placements in all.
  • Highlight color: #FF0000
    Any color from the standard Windows color picker. Red by default.
  • Ping interval ▸
    From every second to every five minutes.
  • Check now
    Runs a check immediately instead of waiting for the next one.
  • Test issue
    Rehearse an outage. Shows the glow and offline icon for 5 seconds, without touching your connection.
  • About
    Version number and a link to the source.
  • Exit
    Only one copy runs per Windows session. Launching it again while it's running does nothing.

Know what it measures

Small on purpose

IsConnected answers one question: can your computer reach the internet right now? It finds out by pinging two well-known hosts. That keeps it light and fast, and it also sets the limits.

✓What it tells you

  • Whether your connection is up, judged by 8.8.8.8 or 1.1.1.1 answering a ping
  • How long the answer took, in milliseconds, in the tray menu
  • Current download and upload speed of the active adapter

–What it doesn't check

  • Whether one particular site or game server is up. A green icon only says your side works.
  • A slow connection that still works. High ping without dropped packets stays green; the tray menu shows the round-trip time.
  • DNS, captive portals on hotel and airport Wi-Fi, or VPN routing

Some corporate and public networks block ICMP. On those, IsConnected reports offline even while your browser works fine.

Build from source

Get it running

IsConnected is a single .exe. Build it with the .NET 8 SDK and drop it anywhere; turn on Autostart from the menu and it starts with Windows.

  • SystemWindows 10 or 11, x64
  • Runtime.NET 8 Desktop Runtime for the small build; none for the self-contained one
  • Settings%APPDATA%\IsConnected\settings.json
  • Version1.0.0

Lightweight exe

Small and framework-dependent.

git clone https://github.com/beprogressive/isConnected
cd isConnected
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=None -p:DebugSymbols=false -o .\publish

Self-contained exe

For machines without the .NET runtime. The file is much larger.

dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:DebugType=None -p:DebugSymbols=false -o .\publish-self-contained

Default settings
